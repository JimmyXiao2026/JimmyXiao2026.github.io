解码用浏览器自带的解码器（能播就能读）。FLAC 只有在源文件本身就是 FLAC 时才能无损导出（浏览器没有 FLAC 编码器）；MP3 依赖 lamejs，首次使用会从 CDN 加载约 100 KB；OGG 使用 WebCodecs 的 Opus 编码器，不支持的浏览器会自动禁用该选项。封面与标题/艺术家/专辑会写进导出文件。

批量转换

一次拖入多个音频或整个文件夹（含网易云 .ncm），按每首歌自己的声道与采样率转换，最后打包成 ZIP

    全程本地处理，文件不上传。声道与采样率保持歌曲原样；强制 FLAC 时若源本身是有损 MP3，会保留原 MP3 并标注原因（浏览器没有 FLAC 编码器）。批量很大时注意内存占用。

    文档与 PDF 互转

    DOCX → PDF 保留版式与图片；PDF ↔ 图片 / 文本 / DOCX

    DOCX → PDF 会在浏览器里解析 OOXML（段落样式、编号、表格、图片、分页、页眉页脚），自己排版成 A4 页面再光栅化嵌入 PDF，版式与图片都会保留，代价是文字不可选中。PDF → DOCX 仍是内容级（只保留文字）。浮动文本框、公式、图表、SmartArt、EMF/WMF 图片、纵向合并单元格暂不支持。
